# Обложка книги

Положите сюда обложку с именем **`cover.jpg`** — она сама появится в блоке «О книге».

- Пропорции 2 : 3, от 1200 × 1800 px.
- Обложка показывается целиком, без обрезки.

Файл самой книги сюда **не кладите**: всё, что лежит в папке сайта, можно скачать по прямой ссылке. Книгу лучше выдавать через сервис оплаты после покупки.
