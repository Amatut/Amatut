# Трактат

- **`cover.jpg`** — обложка или первая страница трактата: появится в блоке «Трактат» сама. Формат A4 (1 : 1,41), от 1240 × 1754 px.
- **Файл трактата** (например, `treatise.pdf`) — после загрузки нужно один раз поправить ссылку на кнопке «Скачать трактат» в `index.html` (пример — в главном README).
