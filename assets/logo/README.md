# Логотип

| Файл | Где используется |
|---|---|
| `logo-black.webp` / `logo-black.png` | основной, чёрный: шапка и первый экран |
| `logo-gold.webp` / `logo-gold.png` | золотой: только на тёмном фоне (подвал) |
| `source/` | исходные файлы в том виде, в каком они были присланы |

В рабочих версиях убраны только белый фон и пустые поля вокруг. Форма, пропорции и цвета не менялись.
